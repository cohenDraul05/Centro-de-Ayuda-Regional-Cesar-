# Centro de Ayudas - Prosperidad Social Regional Cesar

![Portada](assets/images/banner.png)

## Descripción

Este proyecto es una **plataforma web de apoyo comunitario** desarrollada para Prosperidad Social Regional Cesar, con el propósito de brindar a la ciudadanía un espacio donde encontrar:

- Información clara y accesible.  
- Orientación oportuna.  
- Herramientas prácticas para acceder a programas, servicios y beneficios sociales.  
- Materiales de refuerzo y actividades lúdicas para el fortalecimiento del tejido social.

La web busca acompañar a las comunidades en sus procesos de inclusión social y superación de la pobreza, ofreciendo respuestas ágiles y confiables.

---

## Objetivos del Proyecto

- Crear un **centro de ayuda digital** para la comunidad del Cesar.
- Centralizar información en un formato fácil de usar y consultar.
- Facilitar el acceso a planes, actividades, guías y documentos de apoyo comunitarios.
- Fortalecer la red de líderes sociales de la región con actividades y recursos educativos.
- Promover el desarrollo de capacidades socioemocionales, el trabajo comunitario y la gestión autónoma de iniciativas locales.
- Ofrecer herramientas y orientaciones para acceder de manera efectiva a la oferta social y comunitaria del territorio.

---

## Estructura del Proyecto

La organización del repositorio se basa principalmente en contenidos web estáticos y recursos de apoyo:

```bash
├── Videos/                  # Material audiovisual para capacitaciones y difusión
├── assets/images/           # Imágenes, banners y recursos gráficos
├── css/                     # Hojas de estilo CSS para la web
├── docs/                    # Documentos PDF y materiales descargables
├── ABC.html                 # Página informativa sobre el Componente Social y Comunitario (preguntas frecuentes, definiciones, estrategias)
├── Actividades.html         # Sección de actividades comunitarias y juegos lúdicos para el fortalecimiento grupal
├── Historias.html           # Historial y relatos de cambio en la comunidad
├── Lideres.html             # Red de líderes; actividades de liderazgo y formación
├── Plan Comunitario.html    # Material y presentaciones para la planificación comunitaria
├── guias.html               # Guías prácticas y materiales de apoyo
├── index.html               # Página principal con menú de navegación
└── README.md                # Este documento
```

---

## Explicación de los componentes principales

- **ABC.html:** Presenta preguntas frecuentes sobre el Componente Social y Comunitario, abarca estrategias como Mesas de Inclusión, Ferias de Servicios, Gestión de Oferta y Mercados Locales, incluye definiciones sobre capacidades socioemocionales y criterios de operación local.
- **Actividades.html:** Reúne juegos y dinámicas grupales ("La Telaraña", "Pasa la Pelota", "El Termómetro de Opiniones") para fortalecer el trabajo y liderazgo comunitario.
- **Plan Comunitario.html:** Muestra el proceso de construcción del plan comunitario mediante presentaciones, formularios descargables y orientaciones prácticas.
- **Lideres.html:** Red de líderes, espacio con recursos lúdicos y formativos enfocados en el desarrollo del liderazgo social.
- **guías.html:** Provee acceso directo a materiales complementarios y guías de trabajo para promotores, líderes y beneficiarios.
- **Historias.html:** Relatos inspiradores y ejemplos de éxito comunitario.

Cada archivo HTML está acompañado de hojas de estilo propias (en la carpeta `css/`) y se enlazan documentos PDF, imágenes y recursos multimedia (carpetas `assets/images/`, `docs/`, y `Videos/`).

---

## Alcances del Proyecto

- **Alcance Local y Regional:** Dirigido a comunidades, líderes, promotores y entidades del Departamento del Cesar bajo Prosperidad Social.
- **Inclusión:** Guiar el acceso a la oferta social (salud, educación, cuidado, empleabilidad, inclusión financiera).
- **Empoderamiento comunitario:** Fomentar desarrollo de habilidades socioemocionales y fortalecer tejido social.
- **Documentación:** Ofrecer respuestas claras a dudas frecuentes sobre la aplicación y gestión de programas sociales.
- **Material educativo:** Proveer herramientas prácticas, juegos, y guías fácilmente descargables y reproducibles.

---

## Instalación y Uso

Este proyecto consiste en páginas estáticas y recursos auxiliares, por lo que puede ejecutarse simplemente abriendo el archivo `index.html` en cualquier navegador web moderno.

Para modificar contenido:
- Edite los archivos HTML, CSS y recursos correspondientes.
- Agregue nuevos documentos de apoyo en la carpeta `docs/`, imágenes en `assets/images/`, y material audiovisual en `Videos/`.
